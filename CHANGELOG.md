# Changelog

## 2.0.0 — 2026

- Redesigned responsive interface.
- Added cryptographically secure password generation with unbiased selection.
- Added configurable character categories, emoji mode and ambiguous-character exclusion.
- Added entropy estimate and strength indicator.
- Added quick password generation and session-only history.
- Added local settings persistence and reset.
- Added clipboard fallback and keyboard generation shortcut.
- Added accessibility and reduced-motion support.
- Added automated static QA and browser smoke coverage.

Earlier versions focused on the initial client-side password generator and core browser functionality.
